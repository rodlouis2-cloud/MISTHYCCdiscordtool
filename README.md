# Misthycc Discord Tool

A terminal-based Discord utility toolkit developed by Misthycc, featuring an animated ASCII banner and a customizable command-line interface.

## Features

- Animated ASCII banner with letter-by-letter rendering
- Nuk3 server/T0k3n
- Loading animations and visual transitions
- Interactive command-line menu
- Customizable animation speed
- and other !

## Requirements

- Windows 10/11 or a compatible operating system
- Python 3.10 or newer
- Command Prompt or Windows Terminal

## Installation

Clone the repository:

```bash
git clone [YOUR_REPOSITORY_URL](https://github.com/rodlouis2-cloud/MISTHYCCdiscordtool.git)
cd MISTHYCCdiscordtool
```

Install the required dependency:

```bash
py -m pip install colorama
```

## Usage

Run the tool from your terminal:

```bash
toolbymisthycc.exe
```

Follow the instructions displayed in the terminal to navigate the available options.

## Configuration

You can adjust the banner animation speed in the source code:

```python
animated_banner(speed=0.0015)
```

Lower values make the animation faster, while higher values slow it down.
